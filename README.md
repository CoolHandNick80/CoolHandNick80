## 💻 Personal Projects & Open-Source Repositories

### 🚀 **SpaceShooter (C++ Prototype)**
*   **Repository:** [CoolHandNick80/SpaceShooter](https://github.com)
*   **Detailed Description:** A scrolling arcade space engine-lite written entirely in C++. This project focuses on Game Loop stability and efficient low-level memory management, simulating the performance constraints of retro arcade systems using modern mathematical logic.
*   **Technical Focus & Architecture:**
    *   **2D Vector Math:** Implemented custom algorithms for projectile trajectory calculations, ship acceleration, and linear interpolation for enemy movements.
    *   **Object Pooling Pattern:** Optimized runtime memory by reusing projectile and defeated enemy entities, eliminating lag spikes caused by frequent allocation/deallocation (Garbage Collection/Memory Churn).
    *   **Rigid Collision Detection:** Developed a deterministic collision system based on Axis-Aligned Bounding Boxes (AABB), optimized to handle dozens of entities simultaneously at a stable 60 FPS.
    *   **State Management:** Structured with Finite State Machines (FSM) to cleanly decouple game states (Menu, Gameplay, Game Over, Pause).
